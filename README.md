# java-lotto-precourse

# 🎰 로또 발매기 (Lotto Machine)

---

## 📘 프로젝트 개요
사용자로부터 구입 금액과 당첨 번호를 입력받아  
자동으로 로또를 발행하고, 당첨 결과 및 수익률을 계산해 출력하는 프로그램입니다.  
1등부터 5등까지의 당첨 기준을 따르며, 잘못된 입력에 대한 예외 처리를 수행합니다.

---

## 🧩 구현 기능 목록

### 1. 입력 기능 (View / Controller)
- 구입 금액을 입력받는다.
- 금액은 1,000원 단위로 입력되어야 한다.
- 당첨 번호(6개)와 보너스 번호(1개)를 입력받는다.
- 입력 값이 올바른 형식이 아닐 경우 `[ERROR]`로 시작하는 예외 메시지를 출력하고 다시 입력받는다.

---

### 2. 로또 발행 기능 (Domain / Service)
- 구입 금액에 따라 발행할 로또 개수를 계산한다.
- 1장의 가격은 1,000원이다.
- 1~45 사이의 중복되지 않은 6개 숫자를 랜덤으로 생성한다.
- 발행된 로또 번호는 오름차순으로 정렬하여 출력한다.

---

### 3. 당첨 결과 계산 기능 (Service)
- 사용자가 구매한 모든 로또 번호와 당첨 번호를 비교한다.
- 일치하는 숫자의 개수와 보너스 번호 일치 여부에 따라 등수를 계산한다.
- 각 등수별 당첨 횟수를 집계한다.
- 총 상금과 수익률(%)을 계산한다.
- 수익률은 소수점 둘째 자리에서 반올림한다. (예: `62.5%`, `100.0%`)

---

### 4. 결과 출력 기능 (View)
- 구매한 로또 수량과 각 로또 번호를 출력한다.


---

### 5. 예외 처리 기능
- 구입 금액이 1,000원 단위가 아닐 경우 예외 발생
- 로또 번호가 6개가 아닐 경우 예외 발생
- 로또 번호가 1~45 범위를 벗어날 경우 예외 발생
- 중복된 번호 입력 시 예외 발생
- IllegalArgumentException으로 처리하며, 메시지는 반드시 `[ERROR]`로 시작한다.

---

## 🧱 MVC 구조

| 계층 | 역할 | 구성 클래스 |
|------|------|--------------|
| **Domain** | 로또의 상태와 핵심 로직 정의 | `Lotto`, `Rank`, `LottoResult` |
| **Service** | 로또 발행 및 당첨 계산 처리 | `LottoService` |
| **View** | 사용자 입력 및 출력 담당 | `InputView`, `OutputView` |
| **Controller** | 전체 로또 게임의 흐름 제어 | `LottoController` |
